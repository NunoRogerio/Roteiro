Ligar ao GitHub

Os teus roteiros ficam guardados no repositório Roteiro. Isto faz-se só uma vez em cada telemóvel.

  1. Cria uma chave em github.com/settings/personal-access-tokens.
  2. Em Repository access escolhe Only select repositories e depois Roteiro.
  3. Em Permissions, Contents fica Read and write.
  4. Gera a chave, copia-a e cola-a aqui.

Pesquisa Google

Encontra qualquer sítio como no Google Maps. Basta fazer uma vez: serve todos os telemóveis e convidados.

  1. Em console.cloud.google.com cria um projeto e ativa Places API (New).
  2. Em Credentials, Create credentials, API key.
  3. Em Application restrictions escolhe Websites e junta nunorogerio.github.io/*.
  4. Em API restrictions escolhe só Places API (New). Copia a chave e cola-a aqui.
